Two processes to test

Both end at the farmer: distribute fertilizer, confirm OTP on phone, then check the receipt in Verification.

Process 1 Supplier sends stock directly (no order).

Process 2 Shop orders first, then supplier fulfils.

Process 1: Direct dispatch to farmer

1. Supplier sends fertilizer

Login: supplier1

  1. Open Dispatch
  2. Select batch, destination (retailer or AMCOS), bags
  3. Submit

2. Shop receives stock

Login: retailer1 or cooperative1

  1. Open Receive Fertilizer
  2. Confirm the incoming transfer

3. Give to farmer

Login: cooperative1 (AMCOS) or retailer1

AMCOS: Farmer Registry → Distribute Fertilizer → select batch, farmer, bags

Retailer: Distribute → select buyer and bags

Enter the OTP sent to the phone. Complete the transfer.

4. Check receipt

Open Verification. Open the transfer record and review the receipt and trust seal.

Process 2: Order fertilizer to farmer

1. Shop places order

Login: retailer1 or cooperative1

  1. Open Supplier Catalog
  2. Click Order on a supplier
  3. Select types and bags, delivery address, date
  4. Place Order

2. Supplier dispatches from warehouse

Login: supplier1

  1. Incoming Orders → eye icon
  2. Select a batch with enough stock
  3. Dispatch from [batch]

3. Warehouse manager verifies

Login: warehouse_mgr1

  1. Orders Queue → Verify tab
  2. Verify Dispatch

4. Shop confirms delivery

Login: same shop user from step 1

  1. My Orders → eye icon
  2. Status En route → Confirm Delivery

5. Give to farmer

Same as Process 1 step 3: Distribute Fertilizer, enter OTP on phone.

6. Check receipt

Same as Process 1 step 4: Verification tab → view receipt.

Self registration

Anyone can apply from the Sign Up page on the live app.

  1. Open the app → Sign Up
  2. Choose role (Supplier, Retailer, or Cooperative)
  3. Fill organization details and submit
  4. Account stays pending until admin approves

To test approval: Login as admin → Registrations → review request → Approve or Reject.

Approved users can log in immediately. Rejected users receive a message explaining why.

Database tampering

CoffeeChain stores a secure receipt for verified transfers. If someone changes the database directly, the system detects it.

How to test as admin or regulator:

  1. Login as admin or regulator1
  2. Open Chain Integrity
  3. View transfers and their integrity status
  4. Click Scan to compare database records against stored receipts
  5. A mismatch means data was altered outside the app
  6. Admins receive an alert and SMS when tampering is found
  7. When data is restored to match the receipt, the system marks it as restored

Integrity statuses: ok, mismatch, missing receipt, missing anchor, unchecked.

Tips

  • No stock on dispatch? Supplier needs more bags in the warehouse first.
  • Custom orders: write the fertilizer type and specs in the order form.
  • Bell icon shows all in-app alerts.
  • After farmer distribution, always check Verification for the receipt.
